// Pan / 水平摇镜
// Pack: camera (Camera moves & transitions) · element 01 · Category: Camera Movement
// What happens: The camera stays in place and pivots from left to right; because it is a rotation, near and far layers slide sideways by the same amount.
// Motion spec:
//   - Camera: position fixed (height 1.5 m); yaw only, -0.32 rad → +0.32 rad (-18° → +18°, about 37° in total)
//   - Timing: rotate from 0.5 s to 3.4 s (2.9 s), cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1))
//   - Subject: a person (about 1.8 m tall) stands still 8 m ahead and slides right-to-left in frame
//   - No parallax: mountains, buildings, trees and the person all shift by the same angle (focal length 330 px on a 539×208 card)
//   - Return: hold 3.4–4.2 s, then cross-fade back to the start over the last 0.5 s (one pass = 4.7 s)
//   - Top-right readout shows the angle in whole degrees (-18° → +18°)
// When to use it: To reveal a wide location or to shift attention from one side of the scene to the other.
// Tags: pan, panning, yaw, rotate, horizontal, camera move, reveal
// Size: 539x208 px · Cycle: 9.4 s
// Needs: kit camera -> https://motion-prompt.2077tech.com/api/v1/kit/camera.js
// Live demo: https://motion-prompt.2077tech.com/#025
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 01
// 01 パン: 回転なので全ての層が同じだけ横に流れる
CELLS[0] = shot(camCell((k, w, h, p) => world(k, w, h, cam({ yaw: lerp(-0.32, 0.32, p) }), { person: { x: 0, z: 8 } }),
  p => `${Math.round(lerp(-0.32, 0.32, p) * 57.3)}°`.replace(/^(\d)/, '+$1')));
