// Dutch angle / 荷兰角
// Pack: camera (Camera moves & transitions) · element 12 · Category: Shooting Style & Time
// What happens: A level camera rolls around its lens axis and holds with the horizon on a diagonal.
// Motion spec:
//   - Camera: position fixed (height 1.5 m); roll only, 0 → 0.36 rad (about 21°); the whole picture turns around the frame centre
//   - Timing: 0.6 s to 2.2 s (1.6 s), cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1))
//   - Subject: a person stands still 7 m ahead; horizon, buildings and person all tilt by the same angle
//   - Hold: stays tilted from 2.2 s to 4.2 s (time to read the tilted composition itself)
//   - Return: cross-fade back to the level start over the last 0.5 s (one pass = 4.7 s)
//   - Top-right readout shows the angle (∠ 0° → ∠ 21°)
// When to use it: To express unease, tension or the feeling that something is wrong.
// Tags: dutch angle, dutch tilt, canted angle, oblique, roll, tension, tilted horizon
// Size: 539x208 px · Cycle: 9.4 s
// Needs: kit camera -> https://motion-prompt.2077tech.com/api/v1/kit/camera.js
// Live demo: https://motion-prompt.2077tech.com/#036
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 12
// 12 ダッチアングル
CELLS[11] = shot(camCell((k, w, h, p) => world(k, w, h, cam({ roll: lerp(0, 0.36, p) }), { person: { z: 7 } }), p => `∠ ${Math.round(lerp(0, 0.36, p) * 57.3)}°`, 0.6, 2.2));
