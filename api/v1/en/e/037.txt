// Slow motion / 慢动作
// Pack: camera (Camera moves & transitions) · element 13 · Category: Shooting Style & Time
// What happens: In front of a fixed camera a person rises and falls slowly through a jump while leaves drift down slowly; the whole action is stretched out.
// Motion spec:
//   - Camera: completely fixed (height 1.3 m); only the subject moves
//   - Subject: a person 7 m away takes 3.8 s for one jump (0.5 s to 4.3 s); height = 4q(1-q)×1.1 m, a parabola peaking at 1.1 m, with q linear in time
//   - Both arms are raised while airborne; the person stands still for 0.5 s before the jump and 0.4 s after landing
//   - Leaves: 9 leaves fall from 3.4 m to the ground over 4.7 s while rotating, each offset by 1/9 of the cycle
//   - Top-right readout shows "120fps ×0.25" (playback stretched 4×)
//   - No hold and no cross-fade; loops seamlessly every 4.7 s
// When to use it: To let viewers study a brief action or expression, or to emphasise an emotional peak.
// Tags: slow motion, slow-mo, slomo, high frame rate, 120fps, time stretch, jump
// Size: 539x208 px · Cycle: 9.4 s
// Needs: kit camera -> https://motion-prompt.2077tech.com/api/v1/kit/camera.js
// Live demo: https://motion-prompt.2077tech.com/#037
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 13
// 13 スローモーション
CELLS[12] = shot((k, w, h, u) => {
  const q = P(u, 0.5, 4.3);
  world(k, w, h, cam({ y: 1.3 }), { person: { z: 7, y: jumpY(q), armUp: q > 0 && q < 1 }, extra: leaves(u, 1) });
  return '120fps ×0.25';
});
