// Jump cut / 跳切
// Pack: camera (Camera moves & transitions) · element 17 · Category: Transitions
// What happens: Camera position and framing stay the same while the person's position and the clock jump; time is skipped inside one scene.
// Motion spec:
//   - Join: a straight cut with no effect (0 frames); 5 shots of 0.94 s each (4.7 s ÷ 5)
//   - Camera: identical position and framing in every shot (height 1.4 m, facing forward); the background does not move by a pixel
//   - What changes: the person (7 m away) jumps in sideways position, -2.2 m → 1.4 m → -0.4 m → 2.4 m → 0.6 m; in shots 2 and 4 both arms are raised
//   - Within each shot the person is still (the jump is shown only by the difference in position and pose)
//   - Top-right clock: 10:02 → 10:17 → 10:41 → 11:06 → 11:30, showing that time was skipped in the same place
//   - Shot 5 cuts straight back to shot 1
// When to use it: To tighten pauses in talk or work and raise the pace, or to show time passing quickly.
// Tags: jump cut, cut, time skip, same framing, vlog, ellipsis, edit
// Size: 539x208 px · Cycle: 9.4 s
// Needs: kit camera -> https://motion-prompt.2077tech.com/api/v1/kit/camera.js
// Live demo: https://motion-prompt.2077tech.com/#041
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 17
// 17 ジャンプカット（同じ画角で人物の位置と時刻だけ飛ぶ）
CELLS[16] = shot((k, w, h, u) => {
  const shots = [[-2.2, 0], [1.4, 1], [-0.4, 0], [2.4, 1], [0.6, 0]];
  const times = ['10:02', '10:17', '10:41', '11:06', '11:30'];
  const i = Math.min(4, Math.floor(u / (CYC / 5)));
  const [x, arm] = shots[i];
  world(k, w, h, cam({ y: 1.4 }), { person: { x, z: 7, armUp: !!arm } });
  return times[i];
});
