// Cross dissolve / 叠化
// Pack: camera (Camera moves & transitions) · element 20 · Category: Transitions
// What happens: The next picture is laid over the current one and its opacity rises until it takes over; both show through each other midway.
// Motion spec:
//   - Join: 1.5 s, from 1.5 s to 3.0 s; the incoming picture's opacity goes 0 → 100%
//   - Easing: quadratic ease-in-out (about cubic-bezier(0.45,0,0.55,1)); 50% at 2.25 s
//   - The outgoing picture stays fully opaque underneath and the incoming one is drawn on top (the outgoing one is not faded out first)
//   - Camera: fixed in both pictures (A at height 1.4 m; B at height 1.6 m, pitch +0.1 rad); the subjects do not move either
//   - Only the outgoing picture shows for 0–1.5 s, only the incoming one for 3.0–4.7 s
//   - Alternates A→B and B→A every 4.7 s (9.4 s for the round trip); top-right readout shows "A → B" / "B → A"
// When to use it: To convey a gentle passage of time or change of place, or to move into a memory.
// Tags: cross dissolve, dissolve, crossfade, fade, opacity, blend, transition
// Size: 539x208 px · Cycle: 9.4 s
// Needs: kit camera -> https://motion-prompt.2077tech.com/api/v1/kit/camera.js
// Live demo: https://motion-prompt.2077tech.com/#044
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 20
// 20 クロスディゾルブ
CELLS[19] = shot(abCell((k, w, h, u, A, B) => blend(k, kk => A(kk, w, h), kk => B(kk, w, h), eIOs(P(u, 1.5, 3.0)))));
