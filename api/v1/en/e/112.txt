// Vignette / 暗角
// Pack: photo (Photo looks, lighting & styles) · element 16 · Category: Lens & camera effects
// What happens: The frame darkens smoothly from the corners while the person and the road in the middle stay bright.
// Motion spec:
//   - Scene 2: a street corner; buildings, trees and street lamps (x 114, 292, 494) behind a road at y 132–162; the person stands front left (feet at x 176, y 200, 124 px tall). 
//   - Shape: an ellipse centred on the frame (vertical radius = horizontal × 208/539 × 1.35)
//   - Clear out to 45% of the 334 px horizontal radius, then rgb(32,35,43) rising from 0% to 70% towards the edge
//   - Timing: the effect comes in from 0.4 s to 1.4 s, holds until 4.0 s and is gone again by 4.8 s (one pass = 5 s, cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1)))
// When to use it: To focus attention on the subject, or to suggest an old lens.
// Tags: vignette, vignetting, dark corners, edge darkening, lens falloff, focus
// Size: 539x208 px · Cycle: 5 s
// Needs: kit photo -> https://motion-prompt.2077tech.com/api/v1/kit/photo.js
// Live demo: https://motion-prompt.2077tech.com/#112
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 16
// 周辺減光（ビネット）: 四隅だけがなだらかに暗くなり、中央の人物に目が集まる
CELLS[15] = cell((k, u) => {
  const a = env(u);
  stageStreet(k, BASE);
  // 楕円の放射グラデーション: 半径の45%までは素通し、外へ向かって 0 → 70% の濃さ
  k.save(); k.translate(CW / 2, CH / 2); k.scale(1, CH / CW * 1.35);
  const g = k.createRadialGradient(0, 0, CW * 0.45 * 0.62, 0, 0, CW * 0.62);
  g.addColorStop(0, 'rgba(32,35,43,0)'); g.addColorStop(1, `rgba(32,35,43,${(0.7 * a).toFixed(3)})`);
  k.fillStyle = g; k.fillRect(-CW, -CW, CW * 2, CW * 2); k.restore();
});
