// Low-key / 低调摄影
// Pack: photo (Photo looks, lighting & styles) · element 18 · Category: Tones & finishing looks
// What happens: Most of the frame sinks into darkness and the sun goes out; only the right edge of the bust, lit from the side, stays bright. The histogram hump moves to the left end.
// Motion spec:
//   - Scene 3: a bust on the left (head centre x 140, y 82, radius 28 px) and hills, a house, trees and the sun (x 432, y 54, radius 15 px) on the right. 
//   - Colour: sky #FAF9F7 → #2B2D33, hills → #313339 and #36383E, ground → #24252A, figure → #25272E; the sun and its rings take the sky colour and disappear
//   - The lit right edge of the bust stays, #FFC75A → #FFB547
//   - Histogram: peak centre 0.56 → 0.14, width 0.2 → 0.08
//   - Timing: the effect comes in from 0.4 s to 1.4 s, holds until 4.0 s and is gone again by 4.8 s (one pass = 5 s, cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1)))
// When to use it: For luxurious, tense or mysterious images.
// Tags: low-key, low key, dark, black background, moody, dramatic, chiaroscuro
// Size: 539x208 px · Cycle: 5 s
// Needs: kit photo -> https://motion-prompt.2077tech.com/api/v1/kit/photo.js
// Live demo: https://motion-prompt.2077tech.com/#114
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 18
// ローキー: 画面の大半が暗く沈み、横からの光が当たる縁だけが浮かぶ
CELLS[17] = cell((k, u) => {
  const a = env(u);
  const LOW = Object.assign({}, DARK, { sun: DARK.sky, glow: DARK.sky, person: '#25272E', lit: '#FFB547' });
  stageLand(k, pal(BASE, LOW, a));
  histo(k, lerp(0.56, 0.14, a), lerp(0.2, 0.08, a));
});
