// Black and white / 黑白摄影
// Pack: photo (Photo looks, lighting & styles) · element 19 · Category: Tones & finishing looks
// What happens: The colour drains from the same landscape; the sun and the light on the figure turn grey and the shapes read only by their brightness.
// Motion spec:
//   - Scene 3: a bust on the left (head centre x 140, y 82, radius 28 px) and hills, a house, trees and the sun (x 432, y 54, radius 15 px) on the right. 
//   - Conversion: each colour becomes the grey of its luminance (0.2126R + 0.7152G + 0.0722B), contrast ×1.25 around 140
//   - For example the figure #4D5A75 → about #4D4D4D, the sun #F5A524 → about #B5B5B5
//   - Timing: the effect comes in from 0.4 s to 1.4 s, holds until 4.0 s and is gone again by 4.8 s (one pass = 5 s, cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1)))
// When to use it: For a timeless feel, or when shape, light and expression matter more than colour.
// Tags: black and white, monochrome, b&w, grayscale, desaturated, classic
// Size: 539x208 px · Cycle: 5 s
// Needs: kit photo -> https://motion-prompt.2077tech.com/api/v1/kit/photo.js
// Live demo: https://motion-prompt.2077tech.com/#115
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 19
// モノクロ: 色を抜き、明るさだけで見せる（コントラストを少し強める）
CELLS[18] = cell((k, u) => {
  const a = env(u);
  const GRAY = mapPal(BASE, c => { const g = clamp((lum(c) - 140) * 1.25 + 140, 0, 255); return toHex([g, g, g]); });
  stageLand(k, pal(BASE, GRAY, a));
});
