// Duotone / 双色调
// Pack: photo (Photo looks, lighting & styles) · element 20 · Category: Tones & finishing looks
// What happens: The colours of the same landscape are replaced by a range between just two colours: indigo in the darks and pink in the lights.
// Motion spec:
//   - Scene 3: a bust on the left (head centre x 140, y 82, radius 28 px) and hills, a house, trees and the sun (x 432, y 54, radius 15 px) on the right. 
//   - Two colours: #1F2A5C for the dark end, #FF9FB2 for the light end
//   - Conversion: from each colour’s luminance L, t = ((L − 70) / 180)^2.4, and the two colours are mixed by t (this spreads the light tones apart)
//   - Timing: the effect comes in from 0.4 s to 1.4 s, holds until 4.0 s and is gone again by 4.8 s (one pass = 5 s, cubic ease-in-out (about cubic-bezier(0.65,0,0.35,1)))
// When to use it: To unify posters, music artwork or social images in brand colours.
// Tags: duotone, two-tone, gradient map, color overlay, poster, graphic
// Size: 539x208 px · Cycle: 5 s
// Needs: kit photo -> https://motion-prompt.2077tech.com/api/v1/kit/photo.js
// Live demo: https://motion-prompt.2077tech.com/#116
//
// cells[i](k, w, h, u): k = CanvasRenderingContext2D (already cleared and wrapped in save/restore by the caller), w,h = size, u = seconds in [0, cycle). The picture depends only on u.
// Element code starts here. CELLS, constants and helpers live in the kit.

// @element 20
// デュオトーン: 暗い所を藍、明るい所をピンクの2色だけに置き換える
CELLS[19] = cell((k, u) => {
  const a = env(u);
  const DUO = mapPal(BASE, c => mixc('#1F2A5C', '#FF9FB2', Math.pow(clamp((lum(c) - 70) / (250 - 70)), 2.4)));
  stageLand(k, pal(BASE, DUO, a));
});
