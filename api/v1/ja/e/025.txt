// パン / Pan
// パック: camera (カメラワークと切り替え) · element 01 · カテゴリ: カメラの動き
// 何が起きるか: カメラの位置は変えず、首を左から右へ振る。回転なので手前も奥も同じ量だけ横に流れる。
// 動きの仕様:
//   - カメラ: 位置固定（高さ1.5m）、ヨーだけ -0.32rad → +0.32rad（-18° → +18°、計約37°）
//   - 時間: 0.5秒から3.4秒まで2.9秒かけて回す。イージングは3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当）
//   - 被写体: 人物（身長約1.8m）は正面8m先で動かない。画面上では右から左へ流れる
//   - 視差なし: 山・建物・木・人物が同じ角度ぶん動く（焦点距離330px、539×208のカード）
//   - 戻り: 3.4〜4.2秒は止め、最後の0.5秒で開始状態へクロスフェード（1周4.7秒）
//   - 右上に角度を整数の度で表示（-18° → +18°）
// 使いどころ: 横に広い場所を見せるとき、または視線を左右の別の対象へ移すとき。
// タグ: pan, panning, yaw, rotate, horizontal, camera move, reveal
// サイズ: 539x208 px · 1周: 9.4 s
// Needs: kit camera -> https://motion-prompt.2077tech.com/api/v1/kit/camera.js
// 動く見本: https://motion-prompt.2077tech.com/#025
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 01
// 01 パン: 回転なので全ての層が同じだけ横に流れる
CELLS[0] = shot(camCell((k, w, h, p) => world(k, w, h, cam({ yaw: lerp(-0.32, 0.32, p) }), { person: { x: 0, z: 8 } }),
  p => `${Math.round(lerp(-0.32, 0.32, p) * 57.3)}°`.replace(/^(\d)/, '+$1')));
