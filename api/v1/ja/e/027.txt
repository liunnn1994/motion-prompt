// ドリーイン / Dolly in
// パック: camera (カメラワークと切り替え) · element 03 · カテゴリ: カメラの動き
// 何が起きるか: カメラそのものが被写体へ前進する。手前の物ほど大きく速く流れ、奥の山はほとんど変わらない。
// 動きの仕様:
//   - カメラ: 前（奥行き方向）へ 0m → 5.8m 進む。高さ1.5m、向きと焦点距離（330px＝24mm表示）は固定
//   - 時間: 0.5秒から3.4秒まで2.9秒。3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当）
//   - 被写体: 人物は8m先で動かない。距離が8m → 2.2mになり、画面上の大きさは約3.6倍
//   - 視差あり: 手前の杭（左1.5m・奥3.6m）と岩（右1.6m・奥4.8m）は途中で画面外へ抜ける。120m以上先の山はほぼ同じ大きさ
//   - 戻り: 3.4〜4.2秒は止め、最後の0.5秒で開始状態へクロスフェード（1周4.7秒）
//   - 右上の表示は 24mm のまま変わらない（04 ズームインとの違い）
// 使いどころ: 人物の感情や一点へ、空間の奥行きを感じさせながら寄るとき。
// タグ: dolly, dolly in, push in, track in, move forward, parallax, camera move
// サイズ: 539x208 px · 1周: 9.4 s
// Needs: kit camera -> https://motion-prompt.2077tech.com/api/v1/kit/camera.js
// 動く見本: https://motion-prompt.2077tech.com/#027
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 03
// 03 ドリーイン: カメラ位置が前へ（手前は大きく、奥はほぼそのまま）
CELLS[2] = shot(camCell((k, w, h, p) => world(k, w, h, cam({ z: lerp(0, 5.8, p) }), { person: { z: 8 }, fg: [[-1.5, 3.6], [1.6, 4.8, 'rock']] }),
  p => mm(F0)));
