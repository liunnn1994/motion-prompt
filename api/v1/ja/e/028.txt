// ズームイン / Zoom in
// パック: camera (カメラワークと切り替え) · element 04 · カテゴリ: カメラの動き
// 何が起きるか: カメラの位置は動かさず、レンズの焦点距離だけを伸ばす。画面全体が同じ比率で拡大する。
// 動きの仕様:
//   - カメラ: 位置・向きは固定（高さ1.5m）。焦点距離だけ 330px → 1200px（24mm → 87mm表示、約3.6倍）
//   - 倍率は指数補間: f = 330 × (8/2.2)^p。p は 0.5秒〜3.4秒（2.9秒）の3次イーズインアウト
//   - 被写体: 人物は8m先で動かない。最終の大きさは 03 ドリーインと同じ約3.6倍
//   - 視差なし: 手前の杭・岩、人物、建物、山がすべて同じ比率で大きくなる（重なり方が変わらない）
//   - 戻り: 3.4〜4.2秒は止め、最後の0.5秒で開始状態へクロスフェード（1周4.7秒）
//   - 右上に焦点距離を mm で表示（24mm → 87mm）
// 使いどころ: その場から動かずに一点へ注目を集めるとき。ドリーインより平面的で観察する印象になる。
// タグ: zoom, zoom in, focal length, lens, magnify, telephoto, camera move
// サイズ: 539x208 px · 1周: 9.4 s
// Needs: kit camera -> https://motion-prompt.2077tech.com/api/v1/kit/camera.js
// 動く見本: https://motion-prompt.2077tech.com/#028
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 04
// 04 ズームイン: 位置は固定・焦点距離だけ伸びる（全体が同じ比率で拡大）
CELLS[3] = shot(camCell((k, w, h, p) => world(k, w, h, cam({ f: F0 * Math.pow(8 / 2.2, p) }), { person: { z: 8 }, fg: [[-1.5, 3.6], [1.6, 4.8, 'rock']] }),
  p => mm(F0 * Math.pow(8 / 2.2, p))));
