// トラッキング / Tracking shot
// パック: camera (カメラワークと切り替え) · element 05 · カテゴリ: カメラの動き
// 何が起きるか: 歩く人物と同じ速さでカメラが真横に並走する。人物は画面中央のまま、手前の杭ほど速く後ろへ流れる。
// 動きの仕様:
//   - カメラ: 右へ等速 1.7m/s で横移動（x = -4.0m → +4.0m、4.7秒）。高さ1.3m、向きは正面のまま。イージングなし
//   - 被写体: 人物はカメラと同じ x を歩く（奥7.5m）。画面中央から動かない。脚と腕は sin(u×7)×0.42rad で振る
//   - 視差: 奥4mに1.6m間隔で並ぶ杭が最も速く左へ流れ、木、建物（48m先）の順に遅くなり、山はほぼ動かない
//   - 右上に「→ 1.7m/s」を表示
//   - くり返し: 4.7秒ごとに開始位置へ戻る（杭と地面の格子は継ぎ目が合うが、背景の建物と木は位置が飛ぶ）
// 使いどころ: 歩く・走る人物に付いていき、移動している感じを保ったまま表情や動作を見せるとき。
// タグ: tracking, tracking shot, follow, truck, lateral, sideways, parallax, walk
// サイズ: 539x208 px · 1周: 9.4 s
// Needs: kit camera -> https://motion-prompt.2077tech.com/api/v1/kit/camera.js
// 動く見本: https://motion-prompt.2077tech.com/#029
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 05
// 05 トラッキング: 人物と並んで横移動（手前ほど速く流れる）
CELLS[4] = shot((k, w, h, u) => {
  const x = (u - CYC / 2) * 1.7;
  const fgp = []; for (let i = -12; i <= 12; i++) fgp.push([i * 1.6, 4]);
  world(k, w, h, cam({ x, y: 1.3 }), { person: { x, z: 7.5, walk: u * 7 }, fg: fgp });
  return '→ 1.7m/s';
});
