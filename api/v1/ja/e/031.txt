// クレーンアップ / Crane up
// パック: camera (カメラワークと切り替え) · element 07 · カテゴリ: カメラの動き
// 何が起きるか: カメラが真上へ上昇しながら下を向き、人物を見下ろす構図になる。
// 動きの仕様:
//   - カメラ: 高さ 1.4m → 9m へ上昇。同時に前へ 0m → 1.5m 進む
//   - 向き: 人物（8m先）を画面に収めるよう下へ振る。ピッチ = -0.86 × atan2(高さ-1.0, 8-前進量)。約 -2.5° → -44°
//   - 時間: 0.5秒から3.4秒まで2.9秒。3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当）
//   - 被写体: 人物は動かない。上昇につれて小さくなり、地面の格子が画面いっぱいに広がって地平線は上へ抜ける
//   - 戻り: 3.4〜4.2秒は止め、最後の0.5秒で開始状態へクロスフェード（1周4.7秒）
//   - 右上に高さを表示（↑ 1.4m → ↑ 9.0m）
// 使いどころ: 場面の終わりに人物から離れて全体を見せるとき、場所の広さを明かすとき。
// タグ: crane, crane up, jib, boom up, rise, high angle, camera move
// サイズ: 539x208 px · 1周: 9.4 s
// Needs: kit camera -> https://motion-prompt.2077tech.com/api/v1/kit/camera.js
// 動く見本: https://motion-prompt.2077tech.com/#031
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 07
// 07 クレーンアップ: カメラが上昇し、見下ろしになる
CELLS[6] = shot(camCell((k, w, h, p) => {
  const y = lerp(1.4, 9, p), z = lerp(0, 1.5, p);
  world(k, w, h, cam({ y, z, pitch: -0.86 * Math.atan2(y - 1.0, 8 - z) }), { person: { z: 8 } });
}, p => `↑ ${lerp(1.4, 9, p).toFixed(1)}m`));
