// スローモーション / Slow motion
// パック: camera (カメラワークと切り替え) · element 13 · カテゴリ: 撮り方・時間の演出
// 何が起きるか: 固定カメラの前で人物がゆっくり跳び上がり、葉もゆっくり落ちる。動き全体を引き伸ばして見せる。
// 動きの仕様:
//   - カメラ: 完全に固定（高さ1.3m）。動くのは被写体だけ
//   - 被写体: 人物（7m先）が1回の跳躍に3.8秒かける（0.5秒〜4.3秒）。高さ = 4q(1-q)×1.1m の放物線、頂点1.1m。q は等速
//   - 跳んでいる間は両腕を上げる。跳ぶ前の0.5秒と着地後の0.4秒は立ったまま
//   - 葉: 9枚が高さ3.4mから地面まで4.7秒かけて落ち、回転する。位相を1/9ずつずらして循環
//   - 右上に「120fps ×0.25」を表示（4倍に引き伸ばした再生という設定）
//   - 止め・クロスフェードなし。4.7秒で継ぎ目なくくり返す
// 使いどころ: 一瞬の動きや表情をじっくり見せたいとき、感情の山場を強調するとき。
// タグ: slow motion, slow-mo, slomo, high frame rate, 120fps, time stretch, jump
// サイズ: 539x208 px · 1周: 9.4 s
// Needs: kit camera -> https://motion-prompt.2077tech.com/api/v1/kit/camera.js
// 動く見本: https://motion-prompt.2077tech.com/#037
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 13
// 13 スローモーション
CELLS[12] = shot((k, w, h, u) => {
  const q = P(u, 0.5, 4.3);
  world(k, w, h, cam({ y: 1.3 }), { person: { z: 7, y: jumpY(q), armUp: q > 0 && q < 1 }, extra: leaves(u, 1) });
  return '120fps ×0.25';
});
