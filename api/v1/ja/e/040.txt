// フリーズフレーム / Freeze frame
// パック: camera (カメラワークと切り替え) · element 16 · カテゴリ: 撮り方・時間の演出
// 何が起きるか: 跳び上がった人物が頂点に来た瞬間に映像を止め、1.4秒後に続きから再開する。
// 動きの仕様:
//   - カメラ: 完全に固定（高さ1.3m）。止まるのは映像の時間
//   - 停止: 1.6秒で止め、3.0秒で再開（1.4秒間）。映像時間は 0〜1.6秒は等速、停止中は1.6秒のまま、再開後は u-1.4
//   - 被写体: 人物（7m先）の跳躍は映像時間0.6〜2.6秒の放物線、頂点1.1m。停止位置は頂点ちょうど（進み50%）
//   - 停止中は落ち葉9枚も止まる。葉の速さは 13 スローモーションの1.5倍
//   - 停止の印: 太さ5pxの青い枠と、下中央の一時停止マーク（68×40pxの白い角丸に青い縦棒2本）。出入りは0.12秒のフェード
//   - 右上に停止中だけ「FREEZE」を表示。戻りのクロスフェードなし
// 使いどころ: 決定的な瞬間を強調するとき、止めた画に名前や説明のテロップを載せるとき。
// タグ: freeze frame, still frame, pause, hold, stop motion, highlight
// サイズ: 539x208 px · 1周: 9.4 s
// Needs: kit camera -> https://motion-prompt.2077tech.com/api/v1/kit/camera.js
// 動く見本: https://motion-prompt.2077tech.com/#040
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 16
// 16 フリーズフレーム
CELLS[15] = shot((k, w, h, u) => {
  // 跳躍の頂点で 1.4 秒止める
  const tj = u < 1.6 ? u : u < 3.0 ? 1.6 : u - 1.4;   // 実時間→映像時間
  const q = P(tj, 0.6, 2.6);
  const frozen = u >= 1.6 && u < 3.0;
  world(k, w, h, cam({ y: 1.3 }), { person: { z: 7, y: jumpY(q), armUp: q > 0 && q < 1 }, extra: leaves(tj, 1.5) });
  if (frozen) {
    const a = Math.min(1, (u - 1.6) / 0.12, (3.0 - u) / 0.12);
    k.save(); k.globalAlpha = a; k.strokeStyle = C.blue; k.lineWidth = 5; k.strokeRect(2.5, 2.5, w - 5, h - 5);
    k.fillStyle = 'rgba(255,255,255,.88)'; rr(k, w / 2 - 34, h - 58, 68, 40, 8); k.fill();
    k.fillStyle = C.blue; k.fillRect(w / 2 - 12, h - 49, 8, 22); k.fillRect(w / 2 + 4, h - 49, 8, 22); k.restore();
  }
  return frozen ? 'FREEZE' : '';
});
