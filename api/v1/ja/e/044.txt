// クロスディゾルブ / Cross dissolve
// パック: camera (カメラワークと切り替え) · element 20 · カテゴリ: 切り替え（トランジション）
// 何が起きるか: 前の絵に次の絵を重ね、不透明度を上げていって入れ替える。途中は2つの絵が透けて重なる。
// 動きの仕様:
//   - つなぎ方: 1.5秒から3.0秒までの1.5秒。次の絵の不透明度を 0 → 100%
//   - イージング: 2次のイーズインアウト（cubic-bezier(0.45,0,0.55,1) 相当）。中間の2.25秒で50%
//   - 前の絵は不透明のまま下に置き、その上に次の絵を重ねる（前の絵を先に消さない）
//   - カメラ: 両方の絵とも固定（Aは高さ1.4m、Bは高さ1.6m・ピッチ+0.1rad）。被写体も動かない
//   - 0〜1.5秒は前の絵だけ、3.0〜4.7秒は次の絵だけを見せる
//   - 4.7秒ごとに A→B、B→A を交互に行う（往復で9.4秒）。右上に「A → B」「B → A」
// 使いどころ: 時間の経過や場所の移動を穏やかに伝えるとき、回想へ入るとき。
// タグ: cross dissolve, dissolve, crossfade, fade, opacity, blend, transition
// サイズ: 539x208 px · 1周: 9.4 s
// Needs: kit camera -> https://motion-prompt.2077tech.com/api/v1/kit/camera.js
// 動く見本: https://motion-prompt.2077tech.com/#044
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 20
// 20 クロスディゾルブ
CELLS[19] = shot(abCell((k, w, h, u, A, B) => blend(k, kk => A(kk, w, h), kk => B(kk, w, h), eIOs(P(u, 1.5, 3.0)))));
