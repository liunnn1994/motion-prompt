// ワイプ / Wipe
// パック: camera (カメラワークと切り替え) · element 21 · カテゴリ: 切り替え（トランジション）
// 何が起きるか: 縦の境界線が左から右へ動き、通過した側から次の絵に置き換わる。
// 動きの仕様:
//   - つなぎ方: 1.7秒から2.8秒までの1.1秒。境界線が左端の外（x=-4px）から右端の外（x=543px）へ移動
//   - イージング: 3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当）
//   - 境界線の左側に次の絵、右側に前の絵を表示。どちらの絵も位置は動かさない（押し出しではなく切り抜き）
//   - 境界: 幅4pxの青い縦線を、移動中だけ表示
//   - カメラ: 両方の絵とも固定。被写体も動かない
//   - 4.7秒ごとに A→B、B→A を交互に行う（往復で9.4秒）。右上に「A → B」「B → A」
// 使いどころ: 場面や話題の区切りをはっきり見せたいとき、比較の前後を切り替えるとき。
// タグ: wipe, linear wipe, reveal, clip, edge, left to right, transition
// サイズ: 539x208 px · 1周: 9.4 s
// Needs: kit camera -> https://motion-prompt.2077tech.com/api/v1/kit/camera.js
// 動く見本: https://motion-prompt.2077tech.com/#045
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 21
// 21 ワイプ
CELLS[20] = shot(abCell((k, w, h, u, A, B) => {
  const p = eIO(P(u, 1.7, 2.8)), ex = p * (w + 8) - 4;
  A(k, w, h);
  if (p > 0) { k.save(); k.beginPath(); k.rect(0, 0, ex, h); k.clip(); k.fillStyle = '#fff'; k.fillRect(0, 0, w, h); B(k, w, h); k.restore(); }
  if (p > 0 && p < 1) { k.fillStyle = C.blue; k.fillRect(ex - 2, 0, 4, h); }
}));
