// ブルーアワー / Blue hour
// パック: photo (写真の表現・光と画風) · element 08 · カテゴリ: 光の当て方・時間帯
// 何が起きるか: 太陽が沈みきると、空が深い青の2段になり、建物の窓と街灯がアンバーに灯り、人物は青い影の形になる。
// 動きの仕様:
//   - 場面①: 地平線（y150）の前に胸から上の人物（頭の中心 x270, y78・半径29px、顔・髪なし）。
//   - 太陽: 半径18px、x120 で y40 → y190 へ沈む（効果の量が70%に達するまで）。40〜80%で消える
//   - 色: 空 上 #2C3B5E・地平線近く #4A6191、地面 #283452、建物 #34446B、人物 #1C2439
//   - 灯り: 窓の3つに1つと街灯の電球が #FFC75A。電球の周りに半径13px・8pxの平らな光の輪（#FFE3A3、35%・60%）
//   - 右上の時刻 12:00 → 18:35
//   - 時間: 0.4〜1.4秒で効果が入り、4.0秒まで保ち、4.8秒までに元へ戻る（1周5秒、3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当））
// 使いどころ: 夜景を、真っ暗になる前の青い空と街の灯りの両方で見せたいとき。
// タグ: blue hour, twilight, dusk, night city, cityscape, deep blue sky
// サイズ: 539x208 px · 1周: 5 s
// Needs: kit photo -> https://motion-prompt.2077tech.com/api/v1/kit/photo.js
// 動く見本: https://motion-prompt.2077tech.com/#104
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 08
// ブルーアワー: 日が沈んだ後、空が深い青になり、窓と街灯の暖かい光が灯る
CELLS[7] = cell((k, u) => {
  const a = env(u);
  const p = pal(BASE, NIGHT, a);
  stagePortrait(k, p, {
    sun: [120, lerp(40, 190, P(a, 0, 0.7)), 18, 1 - P(a, 0.4, 0.8)],
    after: D => { const k2 = D.k; k2.save(); k2.globalAlpha = 0.35 * a; D.circ(413, HZ - 53, 13, BASE.glow); k2.globalAlpha = 0.6 * a; D.circ(413, HZ - 53, 8, BASE.glow); k2.restore(); D.circ(413, HZ - 53, 4, p.bulb); }
  });
  bust(k, PX, PY, PR, p.person);
  hud(k, clock(lerp(720, 1115, a)));
});
