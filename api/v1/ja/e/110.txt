// 魚眼レンズ / Fisheye lens
// パック: photo (写真の表現・光と画風) · element 14 · カテゴリ: レンズ・カメラの効果
// 何が起きるか: 街角の中心がふくらみ、建物の縦の線と道の横の線が外側へ丸く曲がり、四隅はそのまま残る。
// 動きの仕様:
//   - 場面②: 街角。奥に建物の列・木・街灯（x114, 292, 494）、道は y132〜162、人物は左手前（足元 x176, y200・身長124px）。
//   - 変形: 中心からの距離 d の点を g = (1 + k) / (1 + k·d²/R²) 倍に動かす。R = 中心から角までの距離（289px）
//   - k: 0 → 1.25。中心は2.25倍に拡大、四隅は動かない
//   - 形の輪郭は6pxおきに刻んでから変形するので、直線が曲線になる
//   - 右上の焦点距離 24mm → 8mm
//   - 時間: 0.4〜1.4秒で効果が入り、4.0秒まで保ち、4.8秒までに元へ戻る（1周5秒、3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当））
// 使いどころ: 迫力・遊び心・のぞき穴のような視点を出したいとき（スケボー、ミュージックビデオなど）。
// タグ: fisheye, fisheye lens, barrel distortion, ultra wide, 8mm, distortion
// サイズ: 539x208 px · 1周: 5 s
// Needs: kit photo -> https://motion-prompt.2077tech.com/api/v1/kit/photo.js
// 動く見本: https://motion-prompt.2077tech.com/#110
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 14
// 魚眼レンズ: 中心がふくらみ、建物の縦の線が外側へ丸く曲がる
CELLS[13] = cell((k, u) => {
  const a = env(u), kk = 1.25 * a, cx = CW / 2, cy = CH / 2, R2 = cx * cx + cy * cy;
  const M = kk < 0.002 ? null : (x, y) => { const dx = x - cx, dy = y - cy, g = (1 + kk) / (1 + kk * (dx * dx + dy * dy) / R2); return [cx + dx * g, cy + dy * g]; };
  stageStreet(k, BASE, { M });
  hud(k, `${Math.round(lerp(24, 8, a))}mm`);
});
