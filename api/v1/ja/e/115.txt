// モノクロ / Black and white
// パック: photo (写真の表現・光と画風) · element 19 · カテゴリ: 仕上げ・画風
// 何が起きるか: 同じ風景から色が抜け、太陽も人物の縁の光も灰色になり、明るさの差だけで形が見える。
// 動きの仕様:
//   - 場面③: 左に胸像（頭の中心 x140, y82・半径28px）、右に丘・家・木・太陽（x432, y54・半径15px）。
//   - 変換: 各色を明るさ（0.2126R + 0.7152G + 0.0722B）の灰色に置き換え、140を中心にコントラスト1.25倍
//   - 例: 人物 #4D5A75 → 約 #4D4D4D、太陽 #F5A524 → 約 #B5B5B5
//   - 時間: 0.4〜1.4秒で効果が入り、4.0秒まで保ち、4.8秒までに元へ戻る（1周5秒、3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当））
// 使いどころ: 時代を感じさせたいとき、色より形・光・表情を見せたいとき。
// タグ: black and white, monochrome, b&w, grayscale, desaturated, classic
// サイズ: 539x208 px · 1周: 5 s
// Needs: kit photo -> https://motion-prompt.2077tech.com/api/v1/kit/photo.js
// 動く見本: https://motion-prompt.2077tech.com/#115
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 19
// モノクロ: 色を抜き、明るさだけで見せる（コントラストを少し強める）
CELLS[18] = cell((k, u) => {
  const a = env(u);
  const GRAY = mapPal(BASE, c => { const g = clamp((lum(c) - 140) * 1.25 + 140, 0, 255); return toHex([g, g, g]); });
  stageLand(k, pal(BASE, GRAY, a));
});
