// デュオトーン / Duotone
// パック: photo (写真の表現・光と画風) · element 20 · カテゴリ: 仕上げ・画風
// 何が起きるか: 同じ風景の色が、暗い所は藍、明るい所はピンクの2色の間だけに置き換わる。
// 動きの仕様:
//   - 場面③: 左に胸像（頭の中心 x140, y82・半径28px）、右に丘・家・木・太陽（x432, y54・半径15px）。
//   - 2色: 暗い側 #1F2A5C、明るい側 #FF9FB2
//   - 変換: 各色の明るさ L から t = ((L − 70) / 180)^2.4 を求め、2色を t で混ぜる（明るい色どうしの差を広げる）
//   - 時間: 0.4〜1.4秒で効果が入り、4.0秒まで保ち、4.8秒までに元へ戻る（1周5秒、3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当））
// 使いどころ: ポスター・音楽・SNSの画像を、ブランドの色で統一したいとき。
// タグ: duotone, two-tone, gradient map, color overlay, poster, graphic
// サイズ: 539x208 px · 1周: 5 s
// Needs: kit photo -> https://motion-prompt.2077tech.com/api/v1/kit/photo.js
// 動く見本: https://motion-prompt.2077tech.com/#116
//
// cells[i](k, w, h, u) … k = CanvasRenderingContext2D（呼ぶ側でクリアと save/restore 済み）、w・h = サイズ、u = 秒（0 以上 1周 未満）。u だけで絵が決まる。
// ここから要素のコード。CELLS や定数・補助関数は kit にある。

// @element 20
// デュオトーン: 暗い所を藍、明るい所をピンクの2色だけに置き換える
CELLS[19] = cell((k, u) => {
  const a = env(u);
  const DUO = mapPal(BASE, c => mixc('#1F2A5C', '#FF9FB2', Math.pow(clamp((lum(c) - 70) / (250 - 70)), 2.4)));
  stageLand(k, pal(BASE, DUO, a));
});
