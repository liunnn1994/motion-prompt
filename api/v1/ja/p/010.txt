Motion Prompt #010

どういうものか: 行き過ぎてから戻って止まる
見本で起きること: メーターの針が、目標を行き過ぎてから戻って止まる。
仕様:
- 4.7秒で1回。半円のメーター（半径128・線幅26）。目標は全体の0.7（左端から126°）
- 0.25秒に開始: 値 = 0.7 × (1 − e^(−4.6t)·cos(10.5t))。約0.3秒後に目標を約25%行き過ぎ、揺れながら目標に落ち着く
- 行き過ぎた分（目標より先の弧）はコーラルで塗る。目標の位置に黄色の印
- 弧の塗りは青→ミントのグラデーション。針は白・線幅9
- 戻り: 3.7秒から 値 = 0.7 × e^(−7.5t)·cos(8.5t) で 0 へ（0 をわずかに下回ってから止まる）
使いどころ: 要素が到着する動きに勢いと弾力を出したいとき。
