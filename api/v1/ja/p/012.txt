Motion Prompt #012

どういうものか: 形が別の形に変わる
見本で起きること: 丸 → 四角 → 星 → ハートと、形と色がなめらかに変わる。
仕様:
- 4つの形を1.175秒ずつ（丸 → 角を丸く落とした四角 → 星 → ハート → 丸に戻る）。基準の半径64
- 各区間は前半で止まり、最後の0.62〜0.04秒前（0.58秒間）で次の形へ変形
- 形は輪郭上の240点で持ち、同じ番号の点どうしを直線補間する。進み具合は backOut（s=1.6）で少し行き過ぎる
- 色: 青 → コーラル → 黄 → ミント。easeInOut（2乗）で混ぜる
- 変形中は拡大率を 1 + 0.07 × sin(π × 進み具合) でふくらませる
- 下に4つの点。今の形の点が大きく色付きになる
使いどころ: アイコンやロゴを別の形へ、切らずにつなげて変えたいとき。
