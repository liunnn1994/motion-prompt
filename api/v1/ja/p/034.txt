「手持ち（Handheld）」を使ってください。「カメラワークと切り替え」の名前の1つです。
Motion Prompt #034

どういうものか: 手で持って撮ったように小さく揺らす（ハンドヘルド）
見本で起きること: 三脚を使わず手で持ったような、小さく不規則な揺れを画面全体に加える。
仕様:
- カメラ: 位置はほぼ固定。ヨー・ピッチ・ロール・高さに、周期の違う正弦波を重ねた揺れを足す（T = 2π×u/4.7）
- ヨー(rad) = 0.016·sin(3T) + 0.008·sin(7T+1) + 0.004·sin(13T+2)。最大で約±1.6°
- ピッチ(rad) = 0.012·sin(4T+2) + 0.006·sin(9T+0.5) + 0.003·sin(17T+1.2)。最大で約±1.2°
- ロール(rad) = 0.02·sin(5T+1) + 0.008·sin(11T+3)。最大で約±1.6°。高さ = 1.5 + 0.03·sin(6T) m
- 被写体: 人物は6.5m先で動かない。イージングや止めはなく揺れ続ける
- 係数がすべて整数倍なので4.7秒で継ぎ目なく戻る。右上に「HANDHELD」
使いどころ: ドキュメンタリーのような臨場感や、その場にいる感じを出すとき。
