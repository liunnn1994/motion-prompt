Motion Prompt #038

どういうものか: 速い→遅いと速さを変える
見本で起きること: 1つのショットの途中で再生速度を速い状態から遅い状態へ滑らかに変える。左下のグラフが速度を示す。
仕様:
- カメラ: 完全に固定（高さ1.3m）。変わるのは再生速度だけ
- 再生速度: 2.4倍 → 0.25倍。切り替えは1.2秒から1.9秒までの0.7秒、2次のイーズインアウト（cubic-bezier(0.45,0,0.55,1) 相当）
- 被写体: 人物（8m先）が左6mから右へ走る。位置 x = -6 + 映像時間×2.0 m。速い区間で一気に近づく
- 跳躍: x が -1.5m〜2.5m の間で放物線、頂点0.99m、両腕を上げる。約0.94秒で踏み切り、滞空の大半をスローで見せて約3.68秒で着地
- グラフ: 左下に幅120×高さ40pxの速度曲線と現在位置の青い点（半径5px）
- 戻り: 4.2秒で止め、最後の0.5秒で開始状態へクロスフェード。右上に倍率（×2.4 → ×0.3）
使いどころ: 動きの見せ場だけをスローにして、前後はテンポよく進めたいとき。
