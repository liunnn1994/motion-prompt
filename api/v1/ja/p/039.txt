Motion Prompt #039

どういうものか: 長い時間を早送りで見せる
見本で起きること: 固定カメラのまま、朝6時から夕方18時までを数秒に縮める。太陽・雲・人・影が早送りで動く。
仕様:
- カメラ: 完全に固定（高さ1.6m、ピッチ +0.08rad＝約5°上向き）
- 時間: 0.4秒から4.1秒まで3.7秒で12時間ぶん進める。3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当）
- 太陽: 角度 a = -1.25rad → +1.25rad の弧を左から右へ。位置は (sin a×120, cos a×60 - 8) m、奥170m
- 雲3つ: 右へ合計140m流れ、80mごとに循環。人影7つ: 左右18mの幅をそれぞれ6回横切る（奇数番と偶数番は逆向き）
- 建物の影: 太陽と反対側へ伸び、太陽の動きに合わせて向きが振れる（半透明の灰色）
- 戻り: 最後の0.5秒で開始状態へクロスフェード。右上の時計は 06:00 → 18:00 を10分刻みで表示
使いどころ: 長い時間の経過や、街・空・作業の変化を短く見せるとき。
