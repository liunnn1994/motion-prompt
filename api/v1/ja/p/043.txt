Motion Prompt #043

どういうものか: 素早く振ってブレで次へ
見本で起きること: カメラを素早く横に振り、流れてぼけた映像の中で次の場面に入れ替える。
仕様:
- つなぎ方: 1.7秒から2.5秒までの0.8秒。前半0.4秒は前の絵を振り出し、後半0.4秒は次の絵が振り込んで止まる
- 前半: 前の絵のヨーを 0 → +0.45rad（約26°）、2次のイーズインアウト。後半: 次の絵のヨーを -0.45rad → 0、同じイージング
- 入れ替え: 進み50%の瞬間に直結で差し替える。ぶれが最大なので切れ目は見えない
- ぶれ: 前後1.6フレームぶん（30fps）の範囲を9枚描いて平均する
- カメラ: 高さ1.4m。振っている間以外は固定。被写体（Aは人物、Bは車と街）は動かない
- 4.7秒ごとに A→B、B→A を交互に行う（往復で9.4秒）。右上に「A → B」「B → A」
使いどころ: 勢いを保ったまま場所や話題を切り替えるとき。
