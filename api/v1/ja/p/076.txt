「ピン留め（Pinning）」を使ってください。「LP・Webサイトの演出」の名前の1つです。
Motion Prompt #076

どういうものか: セクションを止めて中身だけ進める
見本で起きること: 濃紺のセクションが画面いっぱいに来たところで止まり、スクロールし続けると番号と写真がステップ1→2→3と切り替わり、終わると再び流れていく。
仕様:
- スクロール量: 0.3〜3.0秒で 0→500px、3.5〜4.5秒で 500→0（easeInOut 3乗）
- セクション（高さ168・濃紺）はスクロール量110pxで上端に着き、そこから300pxのあいだ止まる（GSAP ScrollTrigger の pin）
- 止まっている間の進み具合 p = (スクロール量 − 110) / 300。左の縦線（長さ124）が p に合わせて朱色で伸びる
- p が 1/3 と 2/3 の所（前後 ±0.07、easeInOut 3乗）で次のステップへ: 番号（46px）が52px、写真（226×124）が124px 上へ送られる
- 300px 進むと止めを外し、セクションは次の白いセクションと一緒に上へ流れる
使いどころ: 手順・特長・ビフォーアフターを、1画面で順番に見せたいとき。
