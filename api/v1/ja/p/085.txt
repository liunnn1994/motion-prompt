Motion Prompt #085

どういうものか: 押した場所から波紋が広がる
見本で起きること: ボタンを押すたびに、押した場所を中心に白い円が広がってボタンの中を満たし、薄れて消える。
仕様:
- ボタン 280×56（朱色・角丸10）。0.7秒に左寄り、2.9秒に右寄りの場所をクリック
- 円の中心 = クリックした点。半径 0 → クリック点から一番遠いボタンの角までの距離、0.6秒で（easeOut 3乗）
- 色は白・不透明度0.4。クリックから0.3〜0.8秒で 0 まで薄くする
- 円はボタンの形で切り取る（overflow: hidden）。文字は円の上に描く
使いどころ: ボタンやリストを押したことを、その場ですぐ返したいとき。
