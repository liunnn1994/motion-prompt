Motion Prompt #100

どういうものか: 真横からの光で顔を半分ずつ明暗に分ける
見本で起きること: 光が正面寄り（20°）から真横（90°）へ回り、頭の影が三日月から半分へ広がって、顔が鼻筋の位置で縦に明暗2つに分かれる。
仕様:
- 場面①: 地平線（y150）の前に胸から上の人物（頭の中心 x270, y78・半径29px、顔・髪なし）。背景は一段暗い場面（空 #E7E5E1）へ
- 光: 画面の左から。角度 20° → 90°（右下の配置図と右上の表示「90° · ↑0°」）
- 頭: 明暗の境 x = 270 + cos(角度)·√(29² − dy²) より右が影 #33405A、左が光 #FFC75A。90°で中心線の真っすぐな境
- 胴（半幅56px）: 境 x = 270 + cos(角度)·56 より右が影、左端の帯が光
- 時間: 0.4〜1.4秒で効果が入り、4.0秒まで保ち、4.8秒までに元へ戻る（1周5秒、3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当））
使いどころ: 強さや緊張感のある人物写真にしたいとき。
