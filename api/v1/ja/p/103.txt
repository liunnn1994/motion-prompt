どういうものか: 日没前・日の出後の低く赤みのある光
見本で起きること: 太陽が地平線近くまで下り、空と地面が橙に染まり、人物の左側が光り、街灯と木の影が右へ長く伸びる。
仕様:
- 場面①: 地平線（y150）の前に胸から上の人物（頭の中心 x270, y78・半径29px、顔・髪なし）。
- 太陽: 半径18px、(x110, y−30) → (x96, y136)。丘に半分隠れる
- 色: 空 #FAF9F7 → 上 #FFE8BC・地平線近く #FFCF80、地面 #F1F0EE → #F6DDB0。人物の光 #FFB547・影 #3E3650
- 頭: 光は左から約66°、境より右が影。胴は左側が光・右側が影
- 影: 街灯と木の根元から右へ、長さ 0 → 150px（色 #DDAA6E）。右上の時刻 12:00 → 17:40
- 時間: 0.4〜1.4秒で効果が入り、4.0秒まで保ち、4.8秒までに元へ戻る（1周5秒、3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当））
使いどころ: あたたかく、なつかしく、やさしい雰囲気の写真にしたいとき。
