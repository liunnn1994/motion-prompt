Motion Prompt #113

どういうものか: 明るい色だけで作る、白っぽく影の薄い写真
見本で起きること: 風景と人物が白に近い明るい色だけになり、影はごく薄くなって、右下のヒストグラムの山が右端へ寄る。
仕様:
- 場面③: 左に胸像（頭の中心 x140, y82・半径28px）、右に丘・家・木・太陽（x432, y54・半径15px）。
- 色: 空 #FAF9F7 → #FFFFFF、丘 #EAEDF1 → #F5F6F8、人物 #4D5A75 → #B9C0CE、影 #33405A → #A6AEBF、太陽 #F5A524 → #FFD889
- ヒストグラム（96×46px・20本）: 山の中心 0.56 → 0.85、幅 0.2 → 0.09
- 時間: 0.4〜1.4秒で効果が入り、4.0秒まで保ち、4.8秒までに元へ戻る（1周5秒、3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当））
使いどころ: 清潔感・軽やかさ・やさしさを出したい商品や人物の写真で。
