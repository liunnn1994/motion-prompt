Motion Prompt #114

どういうものか: 暗い色が中心の、光の当たる所だけが浮かぶ写真
見本で起きること: 画面の大半が暗く沈み、太陽も消えて、横から日の当たる胸像の右の縁だけが光って浮かぶ。ヒストグラムの山は左端へ寄る。
仕様:
- 場面③: 左に胸像（頭の中心 x140, y82・半径28px）、右に丘・家・木・太陽（x432, y54・半径15px）。
- 色: 空 #FAF9F7 → #2B2D33、丘 → #313339・#36383E、地面 → #24252A、人物 → #25272E。太陽と光の輪は空と同じ色になって消える
- 胸像の右の縁（光の面）は残り、#FFC75A → #FFB547
- ヒストグラム: 山の中心 0.56 → 0.14、幅 0.2 → 0.08
- 時間: 0.4〜1.4秒で効果が入り、4.0秒まで保ち、4.8秒までに元へ戻る（1周5秒、3次のイーズインアウト（cubic-bezier(0.65,0,0.35,1) 相当））
使いどころ: 高級感・緊張感・ミステリアスな雰囲気を出したいとき。
