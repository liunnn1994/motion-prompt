// 水平摇镜 / Pan
// 素材包: camera (镜头运动与转场) · element 01 · 分类: 镜头运动
// 示例内容: 相机原地水平转动，近景和远景的横向位移相同。
// 动画规格:
//   - 相机：机位固定，高度 1.5m，仅改变水平朝向，−0.32rad→+0.32rad，即 −18°→+18°，总幅度约 37°。
//   - 时序：0.5–3.4 秒转动，时长 2.9 秒，使用三次缓入缓出，约为 cubic-bezier(0.65,0,0.35,1)。
//   - 主体：身高约 1.8m 的人物站在前方 8m 处不动，在画面中从右向左移动。
//   - 无视差：山、建筑、树和人物的角位移相同，539×208 卡片中使用 330px 焦距。
//   - 回到起点：3.4–4.2 秒停留，最后 0.5 秒交叉淡化至初始状态，每轮 4.7 秒。
//   - 右上角以整数角度显示 −18°→+18°。
// 适用场景: 适合展示宽阔环境，或将注意力从画面一侧引向另一侧。
// 标签: pan, panning, yaw, rotate, horizontal, camera move, reveal
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://motion-prompt.2077tech.com/api/v1/kit/camera.js
// 动态示例: https://motion-prompt.2077tech.com/#025
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（由调用方清空画布并执行 save/restore），w、h = 尺寸，u = 秒数，范围为 [0, cycle)。画面仅由 u 决定。
// 以下为素材代码。CELLS、常量及辅助函数位于 kit 文件中。

// @element 01
// 01 パン: 回転なので全ての層が同じだけ横に流れる
CELLS[0] = shot(camCell((k, w, h, p) => world(k, w, h, cam({ yaw: lerp(-0.32, 0.32, p) }), { person: { x: 0, z: 8 } }),
  p => `${Math.round(lerp(-0.32, 0.32, p) * 57.3)}°`.replace(/^(\d)/, '+$1')));
