// 手持拍摄 / Handheld
// 素材包: camera (镜头运动与转场) · element 10 · 分类: 拍摄手法与时间控制
// 示例内容: 整幅画面出现轻微的不规则抖动，像手持相机拍摄。
// 动画规格:
//   - 相机：位置基本不变，水平角、俯仰角、横滚角和高度分别叠加不同周期的正弦波，T = 2π×u/4.7。
//   - 水平角 yaw = 0.016·sin(3T) + 0.008·sin(7T+1) + 0.004·sin(13T+2)，单位 rad，最大约 ±1.6°。
//   - 俯仰角 pitch = 0.012·sin(4T+2) + 0.006·sin(9T+0.5) + 0.003·sin(17T+1.2)，单位 rad，最大约 ±1.2°。
//   - 横滚角 roll = 0.02·sin(5T+1) + 0.008·sin(11T+3)，单位 rad，最大约 ±1.6°；高度 = 1.5 + 0.03·sin(6T) m。
//   - 主体：人物站在前方 6.5m 处不动；晃动持续发生，无缓动或停留阶段。
//   - 各频率倍数均为整数，因此每 4.7 秒无缝循环；右上角显示“HANDHELD”。
// 适用场景: 适合纪录片质感或身临其境的画面。
// 标签: handheld, camera shake, shaky, documentary, wobble, noise, realism
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://motion-prompt.2077tech.com/api/v1/kit/camera.js
// 动态示例: https://motion-prompt.2077tech.com/#034
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（由调用方清空画布并执行 save/restore），w、h = 尺寸，u = 秒数，范围为 [0, cycle)。画面仅由 u 决定。
// 以下为素材代码。CELLS、常量及辅助函数位于 kit 文件中。

// @element 10
// 10 手持ち
CELLS[9] = shot((k, w, h, u) => {
  const T = u * 2 * Math.PI / CYC;   // 周期をサイクルに合わせて継ぎ目なし
  const n = (a, b, c2) => Math.sin(T * a + b) * c2;
  const yaw = n(3, 0, .016) + n(7, 1, .008) + n(13, 2, .004), pitch = n(4, 2, .012) + n(9, .5, .006) + n(17, 1.2, .003), roll = n(5, 1, .02) + n(11, 3, .008);
  world(k, w, h, cam({ yaw, pitch, roll, y: 1.5 + n(6, 0, .03) }), { person: { z: 6.5 } });
  return 'HANDHELD';
});
