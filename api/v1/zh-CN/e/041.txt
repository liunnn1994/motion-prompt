// 跳切 / Jump cut
// 素材包: camera (镜头运动与转场) · element 17 · 分类: 剪辑与转场
// 示例内容: 机位和取景不变，人物位置与时钟跳变，略过同一场景中的时间。
// 动画规格:
//   - 直接硬切，无转场效果，过渡时长为 0 帧；共 5 个镜头，每个 0.94 秒，即 4.7 秒 ÷ 5。
//   - 各镜头机位和取景相同，高度 1.4m、面向正前方，背景没有任何位移。
//   - 变化：前方 7m 的人物横向位置依次跳至 −2.2m、1.4m、−0.4m、2.4m、0.6m；第 2、4 个镜头中双臂抬起。
//   - 各镜头内人物静止，通过位置和姿态差异表现时间跳跃。
//   - 右上角时钟依次为 10:02、10:17、10:41、11:06、11:30，说明同一地点的时间被跳过。
//   - 第 5 个镜头直接切回第 1 个镜头。
// 适用场景: 适合压缩对话或工作中的停顿，加快节奏。
// 标签: jump cut, cut, time skip, same framing, vlog, ellipsis, edit
// 尺寸: 539x208 px · 周期: 9.4 s
// 依赖: kit camera -> https://motion-prompt.2077tech.com/api/v1/kit/camera.js
// 动态示例: https://motion-prompt.2077tech.com/#041
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（由调用方清空画布并执行 save/restore），w、h = 尺寸，u = 秒数，范围为 [0, cycle)。画面仅由 u 决定。
// 以下为素材代码。CELLS、常量及辅助函数位于 kit 文件中。

// @element 17
// 17 ジャンプカット（同じ画角で人物の位置と時刻だけ飛ぶ）
CELLS[16] = shot((k, w, h, u) => {
  const shots = [[-2.2, 0], [1.4, 1], [-0.4, 0], [2.4, 1], [0.6, 0]];
  const times = ['10:02', '10:17', '10:41', '11:06', '11:30'];
  const i = Math.min(4, Math.floor(u / (CYC / 5)));
  const [x, arm] = shots[i];
  world(k, w, h, cam({ y: 1.4 }), { person: { x, z: 7, armUp: !!arm } });
  return times[i];
});
