// 轮廓光 / Rim light
// 素材包: photo (摄影效果、布光与风格) · element 02 · 分类: 布光与拍摄时段
// 示例内容: 环境变暗，人物左右后方的灯照亮头肩边缘，右下角平面图显示灯位。
// 动画规格:
//   - 场景 1：半身人物站在 y = 150 的地平线前，头部圆心为（270, 78）、半径 29px，不绘制五官或头发。
//   - 背景由明亮转暗，天空为 #2B2D33、地面为 #24252A；人物 #4D5A75→#1F2128。
//   - 在暗色人物后方绘制两层 #FFC75A 琥珀色轮廓，分别左移和右移 3.5px，均上移 2.5px，形成宽 3.5px 的亮边。
//   - 右下角 66×66px 平面图显示左右后方 ±135° 灯位，右上角显示“±135°”。
//   - 时序：0.4–1.4 秒效果逐渐增强，保持至 4.0 秒，4.8 秒前恢复原状；每轮 5 秒，使用三次缓入缓出，约为 cubic-bezier(0.65,0,0.35,1)。
// 适用场景: 适合从暗背景中分离人物或产品，强调外形。
// 标签: rim light, rim lighting, edge light, backlight, kicker, outline, studio
// 尺寸: 539x208 px · 周期: 5 s
// 依赖: kit photo -> https://motion-prompt.2077tech.com/api/v1/kit/photo.js
// 动态示例: https://motion-prompt.2077tech.com/#098
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（由调用方清空画布并执行 save/restore），w、h = 尺寸，u = 秒数，范围为 [0, cycle)。画面仅由 u 决定。
// 以下为素材代码。CELLS、常量及辅助函数位于 kit 文件中。

// @element 02
// リムライト: 周りが暗くなり、斜め後ろ左右の2灯で頭と肩の輪郭だけが細く光る
CELLS[1] = cell((k, u) => {
  const a = env(u);
  stagePortrait(k, pal(BASE, DARK, a));
  k.save(); k.globalAlpha = a; k.fillStyle = BASE.lit;
  for (const dx of [-3.5, 3.5]) { k.save(); k.translate(dx, -2.5); bustPath(k, PX, PY, PR); k.fill(); k.restore(); }
  k.restore();
  bust(k, PX, PY, PR, mixc(BASE.person, DARK.person, a));
  plan(k, [[Math.PI * 0.75, a], [-Math.PI * 0.75, a]]);
  hud(k, '±135°');
});
