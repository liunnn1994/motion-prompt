// 双色调 / Duotone
// 素材包: photo (摄影效果、布光与风格) · element 20 · 分类: 影调与后期风格
// 示例内容: 同一风景的颜色被替换为两种颜色，暗部靛蓝、亮部粉色。
// 动画规格:
//   - 场景 3：左侧为半身像，头部圆心（140, 82）、半径 28px；右侧为山丘、房屋、树和太阳，太阳圆心（432, 54）、半径 15px。
//   - 暗部使用 #1F2A5C，亮部使用 #FF9FB2。
//   - 根据每个颜色的亮度 L，计算 t = ((L − 70) / 180)^2.4，再按 t 混合两种颜色，拉开亮部层次。
//   - 时序：0.4–1.4 秒效果逐渐增强，保持至 4.0 秒，4.8 秒前恢复原状；每轮 5 秒，使用三次缓入缓出，约为 cubic-bezier(0.65,0,0.35,1)。
// 适用场景: 适合用品牌色统一海报、音乐作品或社交图片。
// 标签: duotone, two-tone, gradient map, color overlay, poster, graphic
// 尺寸: 539x208 px · 周期: 5 s
// 依赖: kit photo -> https://motion-prompt.2077tech.com/api/v1/kit/photo.js
// 动态示例: https://motion-prompt.2077tech.com/#116
//
// cells[i](k, w, h, u)：k = CanvasRenderingContext2D（由调用方清空画布并执行 save/restore），w、h = 尺寸，u = 秒数，范围为 [0, cycle)。画面仅由 u 决定。
// 以下为素材代码。CELLS、常量及辅助函数位于 kit 文件中。

// @element 20
// デュオトーン: 暗い所を藍、明るい所をピンクの2色だけに置き換える
CELLS[19] = cell((k, u) => {
  const a = env(u);
  const DUO = mapPal(BASE, c => mixc('#1F2A5C', '#FF9FB2', Math.pow(clamp((lum(c) - 70) / (250 - 70)), 2.4)));
  stageLand(k, pal(BASE, DUO, a));
});
