请使用“滚动进度条（Scroll progress bar）”，它是“落地页与网页效果”中的一种效果。
Motion Prompt #079

含义：顶部进度条显示阅读进度
示例内容：随着文章向下滚动，顶部线条从左向右延长，到页尾时填满。
动画规格：
- 文章分四步从 0 滚至 430px，步长 110px；每步移动 0.45 秒、停留 0.4 秒，使用三次缓入缓出。
- 3.75–4.55 秒从 430px 返回 0。
- 视口顶部显示高 6px 的进度条，浅灰轨道、橙色填充。
- 填充宽度 = 511px × scroll / 430，直接对应滚动比例，类似 CSS animation-timeline: scroll()。
适用场景：适合长文章，提示剩余阅读量。
