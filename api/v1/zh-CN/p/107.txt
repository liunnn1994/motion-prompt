Motion Prompt #107

含义：长时间开快门，将移动灯光记录成线
示例内容：街道进入夜色，汽车几乎消失，车尾拖出红色光轨，对向车道出现白色和琥珀色光轨。
动画规格：
- 场景 2：街角，道路位于 y = 132–162，后方是建筑、树和路灯，路灯 x = 114、292、494；前景左侧人物高 124px，脚部位于（176, 200）。颜色转为夜景，天空 #2C3B5E，每三扇窗中的一扇为 #FFC75A。
- 汽车每 5 秒从 x = −60 移至 600，车身不透明度 100%→10%。
- 尾灯光轨从 x = −60 延伸至汽车位置：y = 145 处为 #FF5B4D、宽 2.6px，y = 149 处为 #FF8A6E、宽 1.4px。
- 对向车道光轨贯穿全宽：y = 135 为 #FFE9B8、宽 2.6px；y = 138.5 为 #FFC75A、宽 1.6px；y = 141.5 为 #FFE9B8、宽 1.2px，随效果增强而淡入。
- 右上角快门读数 1/250→8″。
- 时序：0.4–1.4 秒效果逐渐增强，保持至 4.0 秒，4.8 秒前恢复原状；每轮 5 秒，使用三次缓入缓出，约为 cubic-bezier(0.65,0,0.35,1)。
适用场景：适合静态照片中的车流光轨、丝滑流水或云层。
