通过技能安装

在终端中运行以下命令。安装后，向 AI 说“打开 motion-prompt 素材库”，即可打开此页面。选好素材后，点击“发送给 AI”。

npx skills add liunnn1994/motion-prompt

通过提示词安装

将以下文字粘贴到 Claude Code 或 Codex，AI 会安装技能并介绍使用方法。

请阅读 https://github.com/liunnn1994/motion-prompt，并在当前环境中安装 motion-prompt 技能。安装后，请用三句话告诉我如何使用。

使用方法

  1. 1

    让 AI 打开素材库

    向已安装 motion-prompt 技能的 AI 说“打开 motion-prompt 素材库”，此页面就会在浏览器中打开。

  2. 2

    边看边选

    点击所需素材上的“选择”，可选择多个。已选素材会显示在屏幕底部，也可以添加简短备注，例如“用于片头标题”。

  3. 3

    发送给 AI，提出需求

    点击“发送给 AI”，再告诉它：“请按照这些效果编辑视频的开头。”此按钮会在 AI 打开素材库时出现。

可以这样说

不必记住名称或编号。不确定时，就像查字典一样，让 AI 打开素材库供你挑选。

  • 打开 motion-prompt 素材库
  • 有哪些镜头运动？给我看看列表
  • （选好并发送后）请按照这些效果编辑视频的开头

未安装技能，或已知编号时

如果 AI 没有安装技能，可以点击屏幕底部的“复制已选素材”，将包含示例和规格链接的文字粘贴给它。单个素材也可以在详情中点击“复制提示词”。

如果知道编号，也可以直接说：“使用 motion-prompt 的 #012 和 #045。”

关于参考实现

每个示例都是仅由时间决定画面的 Canvas 2D 函数，无需外部依赖。支持逐帧绘制，也能用于导出视频。
