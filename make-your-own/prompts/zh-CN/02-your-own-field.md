# 提示词 2：制作自己的领域

替换 `<领域>`、`<slug>`，将以下文字交给WorkBuddy、豆包、Codex、Claude Code 等 AI 助手。

```text
阅读 make-your-own/README.zh-CN.md、render.mjs 和现有镜头、动态图形 HTML 示例。

目标：在 make-your-own/examples/<slug>/zh-CN/index.html 制作“<领域>”的中英对照术语素材库。

第一步：选择术语
选出 24 个行业通行术语，分为 3 组，每组 8 个。每组从基础到进阶，避免示例重复。提供中文名称、英文名、简短含义、向 AI 提出的示例请求、画面内容及参考来源，标出不确定项。先给我列表，确认后再编写代码。

第二步：确定视觉风格
询问颜色、字体和视觉参考；如果没有，提供两种方向供选择。所有卡片采用一致的字体和配色，名称必须易读。

第三步：实现
每张卡片直接展示术语对应的变化，隐藏标签后也应能辨别。非视觉领域可使用波形、剖面、前后对比或步骤。
画布为 1200×1350、30fps，每页 8 张卡片，每页一个视频。中文名称约 36px，英文名与描述使用清晰可读的字号。
各卡片采用相同周期，首尾无跳变；周期性效果在一页内完成整数次循环。避免大面积快速闪烁。
每帧必须仅由帧号决定，不使用实际时钟或无固定种子的随机数，不使用 CSS 动画。
保留 window.N_FRAMES、window.renderFrame(i)、window.READY、?page=N、?render=1 契约。
不加载网络资源，使用本机字体，使用代码绘图。

第四步：验证
运行 node render.mjs examples/<slug>/zh-CN/index.html --all --sheet。
逐项查看联系表，修正裁切、重叠、缺字和含义不清的卡片，检查视频首尾衔接。
用 ffprobe 检查 1200×1350、30fps、h264、yuv420p 和时长。
报告术语表、来源、不确定项、字体和文件位置。
```
